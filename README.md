# AppleIQ — початок історії

Мінімалістична сюжетна браузерна гра українською мовою в темних кольорах.

## Проходження

1. На першому екрані одразу починається тест із 20 графічних матриць у темному оформленні. Кожна має сітку 3×3 з пропущеною фігурою та шість різних графічних відповідей A–F. Ключа правильних відповідей немає: будь-який вибір приймається без оцінки.
2. Після тесту гравець отримує початковий сюжетний IQ від **8 до 12**. Результат стабільно залежить від вибраних варіантів.
3. Через **10 секунд** показу результату автоматично починається приблизно 36-секундний мультфільм. Камера від’їжджає від монітора, інші сміються з хлопчика, він плаче й вибігає. У своїй кімнаті він відкриває **Apple=IQ**, читає інструкцію, лягає на ліжко та заплющує очі.
4. У темряві з’являються думки героя. Кнопка **«Далі»** переводить між повністю червоним екраном, червоним квадратом та невдалою спробою обертання.
5. Під час невдалої спроби обертається весь екран разом із кнопкою. Натисніть **«Далі»**, щоб зупинити його й продовжити.
6. Наприкінці повільно обертається лише червоний квадрат. **Потенційний IQ** накопичується приблизно на **0,01 за чотири секунди активного часу**. Початковий IQ у лівому верхньому куті залишається незмінним.

Поточний розділ завершується на обертанні квадрата. Наступні події поки не реалізовані. Усі значення IQ є частиною гри.

## Запуск

Відкрийте `index.html` у сучасному браузері. Встановлення залежностей і збирання не потрібні. Локальний сервер:

```bash
python3 -m http.server 8000
```

Файли вже розміщені в корені репозиторію та готові для GitHub Pages. У налаштуваннях сторінок виберіть публікацію з кореня гілки `main`.

## Файли

| Файл | Призначення |
| --- | --- |
| `index.html` | Розмітка тесту без бічної панелі |
| `style.css` | Темне адаптивне оформлення тесту |
| `app.js` | Графічні матриці, шість варіантів, навігація, початковий IQ і десятисекундна пауза |
| `story.js` | Мультфільм, послідовність сцен, уява та потенційний IQ |
| `story.css` | Повноекранні сцени, обертання та переходи |
| `.nojekyll` | Статична публікація без додаткового оброблення |

## Керування та збереження

У тесті вибирайте відповідь мишею або клавішами **1–6**, а потім натискайте **«Далі»** чи **Enter**. На останньому завданні натисніть **«Завершити»**. До вибору відповіді перехід далі заблоковано. Кнопка **«Назад»** дозволяє змінити попередню відповідь. Мультфільм можна пропустити окремою кнопкою. Кнопки сюжетних сцен також працюють із клавіатури.

Відповіді, місце в мультфільмі, етап вправи, початковий і потенційний IQ зберігаються в поточному браузері. Перезавантаження продовжує проходження. Під час прихованої вкладки сюжет і накопичення потенціалу призупиняються; офлайнового нарахування немає.

Мультфільм малюється кодом із простих геометричних фігур і відтворюється без звуку. Зовнішні зображення, моделі, відео та аудіофайли не потрібні. Шрифт Manrope завантажується через Google Fonts із системною заміною без мережі. Системне зменшення руху вимикає масштабування камери та сповільнює обертання.
