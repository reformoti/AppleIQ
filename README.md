# AppleIQ — експериментальний IQ-тест

Мінімалістична браузерна гра українською мовою в темних кольорах. Під час першого відкриття одразу з’являється перше завдання. Двадцять завдань поділено на п’ять рівнів: від простих на вигляд послідовностей до заплутаних матриць і суперечливих умов.

Ключа правильних відповідей навмисно немає. Будь-який вибраний варіант зараховується без оцінки та автоматично відкриває наступне завдання. Підсумковий «IQ» — стабільне вигадане число від 78 до 158, яке залежить від усього набору відповідей. Це ігрова симуляція, а не вимірювання інтелекту; відповідне пояснення є на екрані результату.

## Запуск

Відкрийте `index.html` у браузері. Встановлення залежностей і збирання не потрібні.

Для запуску через локальний сервер виконайте в теці проєкту:

```bash
python3 -m http.server 8000
```

Відкрийте локальну адресу, яку покаже сервер. Для кнопки «Поділитися результатом» потрібен HTTPS або локальний сервер.

## Керування та збереження

- Натисніть варіант або клавішу **1–4**, щоб записати відповідь і перейти далі.
- Кнопка **«Назад»** дозволяє змінити попередню відповідь.
- Оцінок «правильно/неправильно», пояснень і пропуску завдань немає.
- Відповіді та готовий результат зберігаються в поточному браузері.
- Після перезавантаження відкривається поточне завдання або підсумковий екран.
- Нове проходження запускається кнопкою **«Пройти ще раз»** на екрані результату.

## Файли

| Файл | Призначення |
| --- | --- |
| `index.html` | Розмітка та українські назви елементів інтерфейсу |
| `style.css` | Темне адаптивне оформлення |
| `app.js` | Завдання, ігрова логіка, збереження та тривимірне яблуко |
| `.nojekyll` | Публікація статичних файлів без додаткового оброблення |

Монохромне яблуко створюється кодом. Зовнішні зображення, моделі й аудіофайли не потрібні. Шрифт Manrope завантажується через Google Fonts; без мережі використовується системний шрифт. Обертання враховує системне налаштування зменшення руху.
